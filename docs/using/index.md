# Everyday use

Helman's cards answer questions at increasing depth. Start at the top and click when you want to know more.

| Question | Where |
| --- | --- |
| *What is happening right now?* | [Energy flow card](flow-card.md) |
| *What is this one device or node doing, what is planned, and what did it cost?* | [Node details](node-details.md), opened by tapping an icon |
| *How did the day go, and how will tomorrow go?* | [Inspector](inspector.md) |
| *I want the pool pump on now / the battery charged tonight.* | [Editing the schedule](schedule-editor.md) |
| *Why did Helman plan this?* | [Editing the schedule → Explain automation](schedule-editor.md#explain-automation) |
| *Which devices cost me the most this month?* | [Device reports](device-reports.md) |
| *I only need a small tile.* | [Other cards](other-cards.md) |
